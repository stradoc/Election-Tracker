# TippingPoint

Election results you can explore: a map of every state and county, a slider that shows
what a uniform swing would have changed, and the tipping-point state, the one that decided
the election.

It currently covers presidential results for 2016, 2020 and 2024. Deeper analysis (swing,
turnout, demographics, polling) is planned next, followed by Congress, governors and state
legislatures.

## Run it locally

Requires Node.js 22.18 or newer.

```sh
npm install
npm run data   # downloads MIT Election Lab data and builds data/processed
npm run dev    # opens the API on :8787 and the site on http://localhost:5173
```

### County results (one manual step)

The MIT Election Lab county file requires a short guestbook form before download, so a
script can't fetch it:

1. Open <https://doi.org/10.7910/DVN/VOQCHQ> and download `countypres_2000-2024.csv`.
2. Save it as `data/raw/medsl-president-county/countypres_2000-2024.csv`.
3. Run `npm run data` again.

Until then the map shows states only.

## Data

All data is downloaded or regenerated by the pipeline. None of it is committed to this
repository.

- **Results:** [MIT Election Data and Science Lab](https://electionlab.mit.edu/), U.S. President
  1976–2024 and County Presidential Returns 2000–2024 (CC0).
- **Maine and Nebraska district results:** state certificates of ascertainment (National
  Archives) and official state canvass reports.
- **Map shapes:** [us-atlas](https://github.com/topojson/us-atlas), from U.S. Census Bureau
  boundary files.
